# Aprire Team Guzzetta su Windows

Il programma completo è il file **TEAM-GUZZETTA-STATISTICHE-APRI.html** in questa cartella. Comprende clienti, vendite, pulsanti separati per incassi e spese, quote RE/MAX e report.

1. Apri il file HTML su GitHub e premi **Download raw file** (icona con freccia verso il basso). Scarica il file, senza copiare il testo della pagina GitHub.
2. Apri la cartella **Download** di Windows.
3. Fai clic destro sul file **TEAM-GUZZETTA-STATISTICHE-APRI.html** → **Apri con** → **Microsoft Edge** o **Google Chrome**.

Non servono Node.js, comandi o installazioni.

In alternativa scarica **TEAM-GUZZETTA-STATISTICHE.zip**, scegli **Estrai tutto** e apri il file HTML autonomo contenuto nella cartella estratta. Non occorre aprire `public/index.html`, che è la versione per server.

Il programma si apre con dati dimostrativi e li segnala. Per iniziare con i tuoi dati, usa il comando dedicato dopo aver letto la conferma. I dati vengono conservati nel browser: usa sempre lo stesso browser e lo stesso file, ed esporta regolarmente un backup. Per spostare o sostituire il file, esporta prima il backup e ripristinalo nella nuova copia. Il programma non è collegato al conto bancario e non sincronizza dati fra computer.

Se Windows apre un editor di testo, usa **Apri con** e scegli Edge o Chrome. Se il file termina con `.html.txt`, riscarica il file originale: l'estensione corretta è `.html`.
